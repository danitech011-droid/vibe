# Vibe Check Live

Build a modern social multiplayer quiz game platform called Vibe.

Vibe is a Kahoot-style interactive game where people create quiz rooms, invite friends using a game code, answer questions in real time, and compete on a leaderboard. The app should not be positioned as only a love quiz app. It should feel like a general social connection game where users can play with friends, partners, family, classmates, or communities.

Brand Direction

Product name: Vibe

Personality: Fun, modern, social, energetic, premium

Target audience: Gen Z, couples, friends, communities, event organizers

Design inspiration: Kahoot, Discord, modern mobile games
